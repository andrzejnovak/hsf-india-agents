# Hackathon

The kit is its own repository, data included: **https://github.com/andrzejnovak/hsf-india-hww**, a Higgs → WW
search on simulated ATLAS data (the file of the machine-learning tutorial): measure the signal strength, with
the Higgs mass free in the fit, on sealed datasets with hidden truths.

```bash
git clone https://github.com/andrzejnovak/hsf-india-hww.git && cd hsf-india-hww
```

Submissions go on [its issue 1](https://github.com/andrzejnovak/hsf-india-hww/issues/1); the leaderboard is in
[its README](https://github.com/andrzejnovak/hsf-india-hww#leaderboard). The earlier toy kit
(`andrzejnovak/hsf-india-hackathon`, a Gaussian peak) stays up as a reference.
